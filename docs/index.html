Some songs come with a little silence. Time-synced lyrics appear when a suitable match is available from LRCLIB or your licensed provider. Plain lyrics stay clearly unsynced; missing lyrics get an honest status. Catalogue coverage and timing vary. Songcrumb doesn’t extract lyrics from your player.

v1 source preview · macOS 14+ · arm64
  1. Open the included project.

    Use Songcrumb.xcodeproj in Xcode, choose My Mac, then Run. Or build the source folder with Apple’s Command Line Tools:

    ./Scripts/build.sh
open build/Songcrumb.app
  2. Connect the music you use.

    Enable Spotify or Apple Music in Settings and allow macOS Automation. For YouTube Music, load and pair the included browser companion.

  3. Let the words find you.

    Online lookup is already selected. The public project URL identifies the app to LRCLIB. No personal email, account, audio recording or analytics.

This is a developer build, not a notarized one-click installer. The included README has complete setup steps, permissions and provider details.
